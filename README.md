# Labs

### Articles Labs & Code Samples

Welcome to the [buildSoftwareSystems.com](buildsoftwaresystems.com) code snippets repository. 
This repository contains all the code, lab exercises, and projects featured in my technical blog posts. 

Each folder corresponds to a specific article, allowing you to easily clone, run, and experiment with the code locally. 

### 📁 Repository Structure

The repository is organized by project/article topics. Inside each folder, you will find a dedicated README with specific setup instructions for that lab. 

* 📁 [/retry-without-backoff-makes-your-service-fall-over](./retry-without-backoff-makes-your-service-fall-over) — Measure the impact of retry backoff on CPU usage.

### 🚀 Getting Started

### 1. Clone the Repository

To get all the labs on your local machine, run: 

```bash
git clone https://github.com/buildsoftwaresystems/labs.git
cd labs
```

Use code with caution.

### 2. Run a Specific Lab

Navigate into the directory of the article you are reading: 

```bash
cd [folder-name]
```

Use code with caution.

Follow the specific instructions inside that folder's README.md to install dependencies and run the application.
